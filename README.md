## Описание

**Random Password Generator** — это настольное GUI‑приложение для генерации надёжных паролей с возможностью гибкой настройки.  
Программа написана на Python с использованием библиотеки `tkinter` для интерфейса и `random` для генерации символов.

### Основные возможности

- Выбор длины пароля (от 4 до 50 символов) с помощью ползунка.
- Настройка состава пароля через чекбоксы:
  - Цифры (`0-9`)
  - Латинские буквы (`a-z A-Z`)
  - Специальные символы (`!@#$%^&*()_+-=[]{}|;:,.<>?`)
- Кнопка «Сгенерировать» — создаёт случайный пароль согласно выбранным правилам.
- Таблица истории (до 20 последних паролей) с меткой времени.
- Сохранение истории в файл `passwords_history.json` и автоматическая загрузка при запуске.
- Проверка корректности ввода:
  - Если ни один чекбокс не выбран → пароль не генерируется (появляется предупреждение).
  - Если длина меньше минимальной (4) — ползунок автоматически возвращается в допустимое значение.
- Поддержка Git – репозиторий с `.gitignore` и данным файлом `README.md`.
